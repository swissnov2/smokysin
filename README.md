# Financial Forensic & Fraud Analytics Project

## Overview
This repository focuses on utilizing data analytics techniques to detect anomalies, identify potential fraudulent activities, and perform forensic accounting analysis on financial datasets.

## Analytics Objectives
* **Anomaly Detection**: Identifying unusual transaction amounts, duplicate billing, or out-of-sequence checks.
* **Benford's Law Application**: Testing transaction digit distributions to flag artificially fabricated numbers.
* **Risk Scoring**: Building rule-based logic to flag high-risk accounts or transactions.

## Tech Stack
* **SQL**: For querying large ledger databases and extracting high-risk records.
* **Python (Pandas & NumPy)**: For statistical anomaly detection and data cleaning.
